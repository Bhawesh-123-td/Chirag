SMART INVENTORY — FREE-FEATURE VERSION

Included:
- Purchase and sales inventory
- Vendor name + PAN number
- Stock calculation
- Expenditure, revenue, COGS and profit
- Browser-local storage
- JSON backup
- CSV/Excel-compatible export
- PDF report generation
- Optional Supabase free-tier cloud sync and login

Cloud setup is optional. The app works locally without an account.
To enable cloud sync, create a free Supabase project and follow the comments at the top of app.js.
